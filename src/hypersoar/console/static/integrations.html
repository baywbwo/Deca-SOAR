    How secrets are kept

    • Secret values are write-only. Nobody can read them back from this page, the API or the logs.
    • Stored encrypted for the saved host. Only the broker can decrypt them, the console cannot.
    • Sandbox and Production keep separate settings, secrets and targets.
    • Every change is written to the audit trail with who, when and which fields changed. Values are never written.
